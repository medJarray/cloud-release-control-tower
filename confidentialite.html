Confidentialité

Ce site

  • Pas de cookie, pas de mesure d'audience, pas de publicité, pas de formulaire.
  • Les polices sont servies par le site lui-même : aucune requête vers un service de polices.
  • Pour afficher le numéro de la dernière version, la page interroge l'API publique de GitHub (api.github.com). Rien n'est envoyé d'autre, rien n'est gardé dans ton navigateur.
  • Le site est servi par GitHub Pages. Comme pour toute page de GitHub Pages, GitHub enregistre l'adresse IP des visiteurs pour la sécurité du service : voir la déclaration de confidentialité de GitHub. Les téléchargements passent par les releases GitHub, dans les mêmes conditions.

L'application

  • Pas de compte, pas de serveur Control Tower, pas de télémétrie, pas de vérification de mise à jour.
  • L'app parle directement à tes clusters, à AWS, à GitLab et à Jira, depuis ton poste et avec tes droits. Elle ne fait que des lectures.
  • Tes tokens GitLab et Jira restent sur ton poste, dans un fichier de l'app (crct-secrets.json) lisible par ton compte seulement. « Déconnecter » l'efface.
  • Avec Copilot, ta question et ce que les outils de l'app ont lu partent vers GitHub Copilot, par ton propre compte, secrets masqués. Sans Copilot, rien ne part.
